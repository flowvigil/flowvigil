# FlowVigil

**No more silent failures.**

Workflow monitoring for no-code automation agencies. One dashboard. Every client. Zero surprises.

## Files

- `score.html` — The Silent Failure Scorecard (deployed at flowvigil.com/score)
- `index.html` — Temporary redirect to scorecard (replace with landing page)
- `vercel.json` — Vercel routing config

## Stack

- Hosting: Vercel (free tier)
- DNS: Cloudflare
- Email: Resend (coming in Phase 4)
- Payments: Stripe (coming in Phase 3)

## Deploy

1. Push this repo to GitHub
2. Connect repo to Vercel
3. Set custom domain to flowvigil.com
